# Great Pyrenees Rescue Society: website redesign preview

A static, mobile-first redesign of greatpyreneesrescuesociety.org. All content comes from the current site. Yellow `[...]` tags mark information the rescue needs to supply.

- Rebuild pages: `python3 tools/build.py` (the templates live in tools/build.py, and the dog snapshot is in tools/dogs.json)
- Forms, the PayPal button, the Amazon wish list and the merch store still link to the existing RescueGroups, PayPal, Amazon and Bonfire pages.
- The dog list is a snapshot from Nov 23, 2026. To make it update automatically, connect the RescueGroups.org API.
